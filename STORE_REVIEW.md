# Cruddy Weather reviewer notes

Cruddy Weather is a U.S.-only weather dashboard for the toolbar and new-tab page. It also includes supporting browser search and frequent-site shortcuts.

No reviewer account or API credential is required. The extension's forecast route is public and scoped to the extension experience. Commercial API authentication is a separate product and is not used by this extension.

The default attitude is Mild. Safe contains no profanity. Hot and Spicy are explicit user choices and can contain strong profanity. Active weather alerts are rendered separately and are not converted into jokes.

The extension does not inject into websites and does not request broad host access. It has no background worker, analytics, ads, payment flow, remotely hosted code, or obfuscated source.

To review, open Settings, search for `Austin, TX`, select it, save, and then inspect both the toolbar popup and a new tab.
