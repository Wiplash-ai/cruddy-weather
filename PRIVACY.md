# Cruddy Weather privacy summary

Effective August 11, 2026.

The complete, controlling policy is available at:

https://labs.wiplash.ai/cruddy-weather/privacy/

Cruddy Weather uses a location selected by the user to retrieve a forecast. The extension stores that location, display preferences, attitude level, viewed-copy rotation state, and a cached public copy bundle in local extension storage.

The new-tab page reads up to eight frequent sites from the browser and renders them locally. Those titles and URLs are not sent to Cruddy Weather or Wiplash.ai. A search query is passed to the search provider configured in the browser only after the user submits the search form.

The extension contains no ads or analytics. Wiplash.ai does not sell personal information or use forecast locations, search terms, or browsing activity for advertising or profiling.

Cruddy Weather's use and transfer of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including its Limited Use requirements.

Privacy and data requests: support@wiplash.ai
